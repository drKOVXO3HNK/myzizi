# myzizi

RTS-прототип в духе классической Z:
- отряды роботов,
- захват флагов,
- производство юнитов,
- движение/атака по клику.

## Запуск
Открой `index.html` в браузере.

## Управление
- ЛКМ по своему юниту: выделить
- ПКМ по карте: идти
- ПКМ по врагу: атаковать
- Юнит автоматически захватывает флаги рядом
