# myzizi

RTS-прототип, доработанный в сторону атмосферы и темпа **Z (1996)**:

- карта разбита на **сектора с флагами**;
- владение секторами ускоряет **производство юнитов** (ресурс = время);
- есть **Factory** (сильнее ускоряет прод) и **Garage** сектора;
- нейтральные машины на карте можно **захватить пехотой**;
- состав армии: пехота, ракетчик, танк;
- цель — уничтожить вражеский **Fort**.

## Управление

- **ЛКМ** — выделение (клик/рамка)
- **ПКМ** по земле — движение
- **ПКМ** по врагу — атака
- **Пауза** — кнопка в UI

## Что взято из анализа Z

По материалам (Wikipedia RU/EN, MobyGames) для Z характерны:

- бой за сектора и флаги;
- отсутствие классической экономики/строительства;
- производство через контроль карты;
- захват техники и точек на поле.

Это и перенесено в механику текущего прототипа.

## Ассеты/модели (нашёл через Brave)

- Topdown Tanks, OpenGameArt: <https://opengameart.org/content/topdown-tanks>

Перед импортом в репу обязательно проверь лицензию конкретного ассета (на странице модели).
