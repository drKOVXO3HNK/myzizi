# myzizi

RTS-прототип в духе классической **Z** (без оригинальных ассетов):

- захват флагов и контроль карты,
- тикеты команд (проигрывает сторона, у которой они закончились),
- фабрики спавнят юнитов,
- выбор своего юнита и команды по ПКМ,
- базовый ИИ противника.

## Управление

- **ЛКМ** по синему юниту — выделить
- **ПКМ** по земле — движение
- **ПКМ** по красному юниту — атака

## Запуск

Открой `index.html` в браузере.
